# Data and execution boundary

This prototype is intended only for its bundled synthetic scenarios. The isolated browser receives that HTML locally; other browser requests and WebSockets are blocked. OpenRouter receives the synthetic task, visible page text and controls, action history, and (when using the optional OpenRouter planner) screenshots. The API key is read from the process environment and is not intentionally logged. Do not adapt this to personal pages without reviewing data handling.

The optional SystemOne backend receives the synthetic task, plan, visible controls, history and candidate descriptions. `--fast-images` additionally sends the current PNG screenshot as an inline data URL. It is off by default; text-only servers do not receive images. SystemOne endpoints are restricted to loopback HTTP(S), disallow embedded credentials/query/fragment, and do not follow redirects. Only `FAST_API_KEY`, never the OpenRouter key, is attached to this request. A local server may itself forward requests; inspect its configuration before using it. Its costs are not governed by the OpenRouter ledger and are recorded as unknown.

The model cannot execute JavaScript or shell commands. Coordinates, keys and text are validated, typed text replaces only a focused non-password input, and popups are closed. These restrictions are not a complete security boundary against arbitrary untrusted web content. Playwright and Node run with the permissions of their host process.

Semantic click/fill/select actions use a node reference and observed revision, with fresh state and occlusion checks. Fill only accepts editable non-password inputs; select only accepts an available option. Layout-visible offscreen controls can be scrolled into view. Both baseline and dual modes share these actions. Optional skills run only the three hand-authored workflows in `skill-runner.mjs`; model-supplied code is never evaluated. Each workflow stops on a mismatch and checks completion through the separate lab verifier. Skills are scoped to the bundled pages, not arbitrary websites. Experience records stay under ignored `runs/` and are never automatically promoted into executable skills.

`runs/` and `.env` are ignored by Git. Check artifacts before sharing them. The shared budget ledger and lock apply within one checkout only. Provider metadata and billing remain external dependencies; a client-side limit is not equivalent to a provider-enforced key limit. Unknown charges stop execution rather than retrying.

Do not publish API keys in bug reports. For reproducible bugs, share a sanitized report and synthetic inputs only.

The default Codex planner invokes the official CLI with ChatGPT authentication and refuses API-key login. API-key environment variables are stripped from the child, and its invocation ignores personal configuration and disables shell tools, apps, hooks and delegation. It receives the synthetic screenshot and control state only. Raw CLI events and generated files stay under ignored `runs/`; inspect them before sharing. This route uses your subscription allowance and has no automatic API fallback. Subscription usage is separate from the OpenRouter dollar ledger.
