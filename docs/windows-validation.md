**12 次真实运行全部通过。** 逐步组、技能组、双模型技能组各 4 次。三组成功样本的中位耗时分别为 **150.9、32.6、32.6 秒**。四个任务配对中，双模型技能组相对逐步组的加速比为 **3.92～4.64**；这证明当前订阅 CLI 路线上的桌面技能提速，不证明 Jev 本身带来了额外提速。

## 结论边界

这是两类合成 Windows Forms 任务的初步实验，它们共享“三字段填表—查看确认—提交”的工作流，只改变字段语义、值和布局，不是两个独立第三方应用。使用真实窗口、真实 UIA 控件与真实模型；不等于通用桌面软件或纯截图任务。技能把多次规划请求降为一次，避免了重复模型及 CLI 往返。快速模型的增量收益必须比较 dual-skills 与 skills，不能把技能相对逐步规划的收益全部归因于 Jev。

本次没有与官方 Codex 原生 sky 桌面模式直接比较。旧记事本试跑包含聊天协调和视觉检查开销，不能与本表拼接。这里的三个组共享同一独立 UIA 后端和相同订阅 CLI 调用方式，记录的是这套执行器的收益。

成功率按所有已开始样本记录，失败不剔除；跳过不是成功。少量重复只作描述性比较，不能宣称统计显著或普遍可靠。
